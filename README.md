# Hybrid Topology Visualizer

An interactive web-based application for creating, visualizing, and simulating hybrid computer network topologies. The visualizer allows users to add networking devices, establish connections, and simulate message transmission between devices with animated path visualization.

## 🌐 Live Demo

https://kunjpatel6151.github.io/Hybrid-Topology-Visualizer/

## Features

- Interactive drag-and-drop workspace
- Preloaded hybrid network topology
- Add Routers, Switches, and PCs
- Create and remove network connections
- Delete individual devices or connections
- Simulate message transmission between devices
- Automatic shortest-path routing using Breadth-First Search (BFS)
- Animated packet traversal
- Message transmission log
- Reset simulation and clear topology options

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/kunjpatel6151/Hybrid-Topology-Visualizer.git
```

2. Open the project directory.

3. Launch `index.html` in any modern web browser.

No installation or additional dependencies are required.

## Usage

1. Open the application.
2. Explore the preloaded hybrid topology or build your own.
3. Add routers, switches, and PCs as needed.
4. Connect devices using the **Connect** option.
5. Select the sender and receiver devices.
6. Enter a message.
7. Click **Send** to visualize packet transmission through the network.
